# 🎂 生日快乐 - 生日祝福页面

一个精美的交互式生日祝福HTML页面，包含多个动画效果。

## ✨ 功能特性

### 第一阶段：粒子祝福与倒计时
- 彩色粒子背景动画
- 轮流播放5句生日祝福语
- 5秒倒计时动画

### 第二阶段：生日蛋糕
- 精美的生日蛋糕SVG动画
- 蜡烛火焰燃烧特效
- 点击吹灭蜡烛，产生烟雾效果

### 第三阶段：信封轮播
- 4封生日祝福信封
- 向下轮播切换效果
- 查看全部信封后解锁继续按钮

### 第四阶段：烟花秀
- 绚丽的烟花动画特效
- "生日快乐"最终祝福展示
- 支持重播功能

## 🚀 使用方法

### 直接打开
直接在浏览器中打开 `index.html` 文件即可。

### 本地服务器（可选）
```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (http-server)
npx http-server

# 然后访问 http://localhost:8000
```

## 🎨 自定义内容

你可以通过编辑 `index.html` 文件来自定义内容：

### 修改祝福语
找到 `blessings` 数组：
```javascript
const blessings = [
    "✨ 生日快乐 ✨",
    "🎂 愿你梦想成真 🎂",
    // 添加更多祝福语...
];
```

### 修改信封内容
找到HTML中的 `.envelope` 元素：
```html
<div class="envelope" data-index="0">
    <h3>🌟 愿你</h3>
    <p>每一天都充满阳光和欢笑<br>所有的愿望都能实现</p>
</div>
```

## 📱 响应式设计

页面支持各种屏幕尺寸，包括手机、平板和桌面设备。

## 🎯 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- Canvas 粒子系统
- Canvas 烟花效果
- CSS3 动画
- 无需任何外部依赖库
